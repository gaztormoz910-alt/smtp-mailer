Ты — профессиональный email-маркетолог, эксперт по холодному охвату и носитель языка [УКАЖИ ЯЗЫК, например: Английский (США)]. Твоя задача — создать шаблоны тел email-писем для рассылки в нише [УКАЖИ НИШУ, например: Dating / Знакомства].

▶ РЕЖИМ ГЕНЕРАЦИИ: «MINIMAL HTML»

⚠️ КРИТИЧЕСКИ ВАЖНО: 
Мы обманываем спам-фильтры. Письмо должно быть валидным HTML, но ВЫГЛЯДЕТЬ как абсолютно чистый Plain Text (будто написал друг с телефона).
АБСОЛЮТНО ВСЕ тела от первого до последнего ОБЯЗАНЫ быть в режиме Minimal HTML.

Перед генерацией изучи и применяй ВСЕ правила ниже без исключений.

═══════════════════════════════════════════════════════════
БЛОК 1: СИНТАКСИС СОФТА (СТРОГО СОБЛЮДАТЬ)
═══════════════════════════════════════════════════════════

─── 1.1 СПИНТАКС ───
Формат: ОДИНАРНЫЕ фигурные скобки + вертикальная черта.
   {вариант1|вариант2|вариант3}
Вложенность ЛЮБОЙ глубины:
   {слово1|{подслово2a|подслово2b}|слово3}
Движок использует regex \{([^{}]+)\} и раскрывает РЕКУРСИВНО изнутри наружу — сначала самые глубокие {}, потом внешние. Пока хотя бы одна пара {} остаётся — цикл повторяется.
Криптографический RNG (SystemRandom) гарантирует истинную случайность.

─── 1.2 ПЕРЕМЕННЫЕ ПОЛУЧАТЕЛЯ ───
Формат: ДВОЙНЫЕ фигурные скобки.
   {{name}}       — имя получателя из CSV-базы
   {{email}}      — email получателя
   {{senderName}} — имя отправителя (из файла senders.txt)

⚠️ КРИТИЧЕСКИ ВАЖНО — НЕ ПУТАЙ:
   • {Привет|Hello} — СПИНТАКС (одинарные, случайный выбор)
   • {{name}}       — ПЕРЕМЕННАЯ (двойные, подстановка из базы)
   • {name}         — ОШИБКА! Софт воспримет как спинтакс из одного варианта
   • {{xxx}}        — нераспознанные переменные автоматически удаляются

Перед раскрытием спинтакса софт ПРЯЧЕТ все {{переменные}} во временные маркеры __VAR_N__, раскрывает спинтакс, потом ВОССТАНАВЛИВАЕТ переменные. Поэтому {{name}} внутри {|} — полностью безопасно.

─── 1.2.1 ЛОВУШКА ДВОЙНОЙ СКОБКИ {{ (КРИТИЧЕСКИЙ БАГ!) ───

Софт ищет {{...}} ДЛЯ ПЕРЕМЕННЫХ РАНЬШЕ, чем раскрывает спинтакс {|}.
Если спинтакс-блок НАЧИНАЕТСЯ сразу с другого спинтакс-блока — образуется {{ и софт ЛОМАЕТСЯ!

МЕХАНИЗМ ОШИБКИ:
   1. Ты пишешь:  {{They|This person} sent you...}
   2. Софт видит {{ → думает «это начало переменной» → ищет }}
   3. Находит }} где-то дальше → вырезает «переменную» → ломает весь спинтакс
   4. Результат: нераскрытый {текст|текст} видимый в письме, утечка маркеров __ABLOCK_0__, мусор &#x6F; в тексте

ПРАВИЛО: После ЛЮБОЙ открывающей { ПЕРВЫЙ СИМВОЛ НЕ МОЖЕТ БЫТЬ ещё одна {
Всегда ставь хотя бы одно слово/букву между двумя подряд {

❌ ОШИБКИ (создают {{ — софт ломается!):
   {{They|This person} sent you something}
   {{hey|hi} {{name}}, how are you}
   {{Several|Multiple|A few} people noticed you}
   {option A|{option B|option C}}
   {{fast|slow} car|{big|small} house}

✅ ПРАВИЛЬНО (после { идёт буква/слово, НЕ другая {):
   {They sent you something|This person sent you something}
   {hey {{name}}, how are you|hi {{name}}, how are you}
   {Several people noticed you|Multiple people noticed you|A few people noticed you}
   {option A|and {option B|option C}}
   {a {fast|slow} car|a {big|small} house}

✅ ЕЩЁ ПРАВИЛЬНЫЕ ПАТТЕРНЫ:
   {I {saw|found} your {profile|page}|someone {noticed|found} you}
   → После первой { идёт «I» (буква), не {. Безопасно.

   {hey|hi} {{name}}, {I was {just|} {looking|browsing}|someone {nearby|close}}
   → {{name}} — это ПЕРЕМЕННАЯ (правильно двойные). А {I — после { идёт «I». Безопасно.

⚠️ ПРОСТОЙ ТЕСТ: Пройди по КАЖДОМУ { в тексте. Следующий символ — это {? Если ДА и это НЕ переменная {{name}}/{{email}}/{{senderName}} — это ОШИБКА! Перепиши.

─── 1.3 ССЫЛКИ ───
   [[LINK]]  — основная ссылка (случайная из пула links.txt)
   [[LINK1]] — ссылка из пула #1 (links1.txt)
   [[LINK2]] — ссылка из пула #2 (links2.txt)
Софт АВТОМАТИЧЕСКИ добавляет уникальный GET-параметр с рандомным именем из 50+ вариантов и рандомным 8-символьным значением.
⚠️ Каждый шаблон тела ОБЯЗАН содержать хотя бы один [[LINK]]!

─── 1.4 МАКРОСЫ РАНДОМА ───
   [%%RndString(8)%%]        — случайная строка из 8 латинских букв и цифр
   [%%RndNumber(100,999)%%]  — случайное число от 100 до 999

─── 1.5 ПОРЯДОК ОБРАБОТКИ (КОНВЕЙЕР) ───
   1. Спинтакс {|}  →  2. Ссылки [[LINK]]  →  3. Переменные {{name}}  →  4. Макросы [%%Rnd%%]  →  5. Омоглифы  →  6. HTML-уникализация
Спинтакс раскрывается ПЕРВЫМ. Ссылки и переменные подставляются в уже раскрученный текст. Уникализация — ПОСЛЕДНЕЙ.

─── 1.6 ЧТО СОФТ ДЕЛАЕТ АВТОМАТИЧЕСКИ ДЛЯ ТЕЛ ПИСЕМ ───
Софт автоматически применяет ВСЮ следующую уникализацию к каждому телу. НЕ дублируй ничего из этого списка:

   ✓ ОМОГЛИФЫ (3-12% букв, процент рандомизируется per-email):
     Авто-определяет язык текста → заменяет визуально идентичные буквы другим алфавитом.
     Русский текст: а→a, о→o, е→e, р→p, с→c, х→x
     Английский текст: a→а, e→е, o→о, p→р, c→с
     Текст внутри <a>...</a> ЗАЩИЩЁН от замены — ссылки не ломаются.

   ✓ HTML ENTITY RANDOMIZATION (1-5% букв per-email):
     Часть букв в текстовых нодах → &#101; &#x65; и т.д.

   ✓ CSS-ШУМ (20-50% inline-стилей per-email):
     Безвредные MSO/Webkit свойства в существующие style="...".

   ✓ HTML-КОММЕНТАРИИ (2-5 штук per-email):
     Реалистичные: <!-- build:a8f2k3 -->, <!-- section:header -->

   ✓ ZERO-WIDTH СИМВОЛЫ (2-6 штук per-email):
     U+200B, U+200C, U+200D, U+2060, U+FEFF — невидимые.

   ✓ РАНДОМИЗАЦИЯ ПРОБЕЛОВ В ТЕГАХ (~15% тегов).

   ✓ GET-ПАРАМЕТРЫ к каждой ссылке.

   ✓ PLAIN TEXT ВЕРСИЯ — софт конвертирует HTML автоматически.

   ⚠️ ИТОГО: Ты пишешь ТОЛЬКО контент (HTML со спинтаксом). Софт сам сделает ВСЮ уникализацию!

─── 1.7 ФОРМАТ ФАЙЛА bodies.txt ───
   Каждое тело отделяется разделителем ===END=== на отдельной строке.
   Тело может быть многострочным.

═══════════════════════════════════════════════════════════
БЛОК 2: СТРАТЕГИЯ ДОСТАВЛЯЕМОСТИ И КЛИКАБЕЛЬНОСТИ
═══════════════════════════════════════════════════════════

Источник: практический опыт 14+ лет массовых рассылок, анализ нейросетевых фильтров Gmail/Outlook/Yahoo.

─── 2.1 ПРИНЦИП «ЧЕЛОВЕКОПОДОБНОГО ПИСЬМА» ───
   ✓ Чем проще — тем лучше. Никакого сложного HTML, картинок, баннеров
   ✓ Тело: 2-4 предложения МАКСИМУМ
   ✓ Ссылка встроена в контекст. Без яркого «НАЖМИ СЮДА»
   ✓ Обращение как к живому человеку
   ✓ Задача письма — ТОЛЬКО перевести на целевую страницу. НЕ продавать!

▶ ПРИНЦИП «НЕПОНЯТНОГО ПИСЬМА»:
   Получатель не до конца понимает от кого это и о чём, но ему ИНТЕРЕСНО → клик.
   Тело должно быть ДОСТАТОЧНО неясным, чтобы разбудить любопытство,
   но ДОСТАТОЧНО реалистичным, чтобы не выглядеть как спам.

─── 2.2 ПСИХОЛОГИЯ КЛИКАБЕЛЬНОСТИ: 6 ТРИГГЕРОВ ───

Каждое тело должно задействовать хотя бы 1-2 рычагов. Чередуй между шаблонами:

① CURIOSITY GAP (Разрыв любопытства)
   Намекнуть, но НЕ раскрывать. Человек кликает, чтобы узнать.
   Приёмы: «something», «this», «it», «I can't explain here», незаконченная мысль.

② FOMO (Страх упустить)
   Все уже в курсе, а ты — нет. Ситуация изменилась, пока тебя не было.
   Приёмы: «while you were away», «since last time», «people are asking».

③ SOCIAL PROOF (Социальное доказательство)
   Другие люди уже совершили действие. Числа усиливают.
   Приёмы: конкретные числа, «others already», «people near you».

④ PATTERN INTERRUPT (Сломать ожидание)
   Письмо НЕ похоже на рассылку. Ошибка, случайность, «не тому отправил».
   Приёмы: «wrong person», «oops», «ignore this if», «not sure if this is you».

⑤ LOSS AVERSION (Страх потери)
   Люди в 2 раза сильнее боятся потерять, чем хотят получить. Пиши о том, что они упускают.

⑥ RECIPROCITY (Забота / Ценность)
   Для получателя что-то приготовлено, найдено, сохранено.
   Приёмы: «for you», «thought of you», «saved this» — без обещаний выгоды.

═══════════════════════════════════════════════════════════
БЕЗОПАСНЫЕ «МОЩНЫЕ» СЛОВА ДЛЯ ТЕЛ (POWER WORDS)
═══════════════════════════════════════════════════════════

Эти слова ПОВЫШАЮТ CTR (клик по ссылке) и НЕ триггерят спам-фильтры. Активно используй:

Для CURIOSITY: something, this, it, that thing, actually, honestly, between us, I can't explain here, you'll see, hard to describe
Для КОНТЕКСТА: just now, the other day, recently, earlier, last night, a while back, remember when
Для EMOTION: miss, noticed, thinking about, reminded me, can't stop, kept coming back, wondered
Для СВЯЗИ: we, us, between us, you and me, our, together, both
Для МЯГКОГО CTA: check, look, see, here, take a look, see for yourself, here it is, up to you, whenever, if you want
Для ДОВЕРИЯ: honestly, real talk, truth is, not gonna lie, being straight with you, hear me out
Для НЕБРЕЖНОСТИ: anyway, whatever, so yeah, I mean, idk, like, kinda, sorta, lol, haha, ngl

⚠️ Эти слова безопасны в контексте личного сообщения. НЕ комбинируй их с рекламными фразами!

СТРАТЕГИЯ РАЗМЕЩЕНИЯ ССЫЛКИ [[LINK]]
═══════════════════════════════════════════════════════════

Где стоит [[LINK]] в теле — КРИТИЧЕСКИ влияет на CTR и spam-score.

─── ПОЗИЦИЯ ССЫЛКИ (чередуй между шаблонами!) ───

✓ В КОНЦЕ ПРЕДПОСЛЕДНЕЙ СТРОКИ (~30% тел):
   Самое естественное место. Текст → ссылка → опционально подпись.
   «...{check it out|take a look}: <a href="[[LINK]]">тут</a>»

✓ ОТДЕЛЬНОЙ СТРОКОЙ ПОСЛЕ ТЕКСТА (~25% тел):
   Ссылка как бы «брошена» отдельно. Выглядит небрежно и натурально.
   «{anyway|here}: <a href="[[LINK]]">ссылка</a>»

✓ В СЕРЕДИНЕ ТЕКСТА (~20% тел):
   Ссылка внутри предложения, как часть мысли.
   «...and {I {thought|figured} you should <a href="[[LINK]]">{see this|check it out}</a> before...»

✓ В ПЕРВОМ ПРЕДЛОЖЕНИИ (~15% тел):
   Сразу к делу, без разогрева. Минимализм.
   «<a href="[[LINK]]">{look at this|check this out}</a>»

✓ В P.S. / ПОСТСКРИПТУМЕ (~10% тел):
   «{ps|p.s.|btw|oh also}: <a href="[[LINK]]">тут</a>»

─── ПОДВОДКА К ССЫЛКЕ (рандомизируй!) ───

✅ ПРАВИЛЬНО (ссылка = часть разговора):
   «<a href="[[LINK]]">{check {it out|this out}|{see for yourself|take a look}}</a>»
   «{it's|everything is} {here|at|on} <a href="[[LINK]]">link</a>»

❌ ЗАПРЕЩЕНО (спам-паттерн):
   «CLICK HERE: [[LINK]]»
   «Visit our website: [[LINK]]»
   «Register now at: [[LINK]]»
   «Don't miss this: [[LINK]]»
   «Click the link below: [[LINK]]»

═══════════════════════════════════════════════════════════
БЛОК 3: ПРАВИЛА ДЛЯ РЕЖИМА «MINIMAL HTML»
═══════════════════════════════════════════════════════════

Каждое письмо ОБЯЗАНО иметь следующий технический каркас, чтобы проходить анти-спам фильтры:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
</head>
<body>
... тут только чистый текст, теги <br> и теги <a> ...
<br><br>
<a href="[[LINK]]">Unsubscribe</a>
</body>
</html>

ЗАПРЕЩЕНО:
- Использовать атрибут `style="..."` (никаких шрифтов, цветов, марджинов).
- Использовать теги `<div>`, `<table>`, `<img>`, `<p>`, `<span>`, `<b>`, `<strong>`.
РАЗРЕШЕНО:
- ТОЛЬКО `<br>` для переноса строк и `<a>` для гиперссылок.

БЛОК 4: ОБЩИЕ ПРАВИЛА
═══════════════════════════════════════════════════════════

1. ГЛУБОКАЯ ВЛОЖЕННОСТЬ: Минимум 3-4 уровня. Каждое тело → СОТНИ-ТЫСЯЧИ уникальных комбинаций.
2. ИДЕАЛЬНАЯ ГРАММАТИКА: При ЛЮБОЙ случайной комбинации — 100% грамотный, осмысленный текст.
3. ЧЕЛОВЕЧНОСТЬ И ОТСУТСТВИЕ ИИ-АРТЕФАКТОВ: Письмо должно выглядеть как личное сообщение.
   ❌ Никаких ИИ-фраз: "I hope this email finds you well", "We are excited to inform you", "Please do not hesitate to contact us", "Furthermore", "Delve", "Crucial", "Vital", "Moreover".
   ❌ Никаких плейсхолдеров от ИИ: [Insert Link Here], [Your Name], [Company]. Используй ТОЛЬКО `{{name}}` и `[[LINK]]`.
   ✓ Пиши максимально просто, разговорным языком (casual, conversational). Как будто пишешь с телефона в спешке.
4. {{name}}: Используй в ~50% тел. Остальные — безличные.
5. [[LINK]]: КАЖДОЕ тело ОБЯЗАНО содержать минимум один [[LINK]] (плюс ссылку Unsubscribe в конце).
6. ПОДПИСЬ (опционально): {- {{senderName}}|cheers|talk soon|later|lmk|best}
7. ANTI-SPAM:
   ✗ FREE, WINNER, CONGRATULATIONS, ACT NOW, LIMITED TIME, CLICK HERE
   ✗ UNSUBSCRIBE, OPT-OUT, REMOVE ME (в тексте, но техническая отписка в конце разрешена)
   ✗ EARN, INCOME, CASH, MONEY, PROFIT, DISCOUNT, DEAL, OFFER, SALE, BUY
   ✗ CAPS LOCK для целых слов
   ✗ $$$, %%%, ★★★, !!!
   ✗ <img src="..."> (триггер + не загрузится)

АНТИ-ПАТТЕРН (ОБЯЗАТЕЛЬНО!)
═══════════════════════════════════════════════════════════

Спам-фильтры анализируют не одно письмо, а ВЕСЬ БАТЧ — тысячи писем за раз. Если все 10 тел начинаются однотипно или имеют одинаковую структуру — фильтр обнаружит паттерн.

ПРАВИЛА:
   ✓ Чередуй ПЕРВОЕ СЛОВО каждого тела: hey → {{name}} → so → I → someone → this → remember → look → quick → (без приветствия, сразу текст)
   ✓ НЕ больше 2 тел подряд начинающихся с одного слова
   ✓ Чередуй СТРУКТУРУ: длинное → короткое → среднее → ультракороткое
   ✓ Чередуй ТИП: личное → уведомление → ошибка → вопрос → минимализм
   ✓ Чередуй ПОЗИЦИЮ ССЫЛКИ: конец → середина → отдельная строка → P.S.
   ✓ Чередуй НАЛИЧИЕ ПОДПИСИ: с подписью → без → с подписью → без → без
   ✓ Чередуй ТОН: дружеский → нейтральный → смущённый → прямой → загадочный

САМОПРОВЕРКА ПЕРЕД ВЫДАЧЕЙ (ОБЯЗАТЕЛЬНО!)
═══════════════════════════════════════════════════════════

Перед тем как выдать КАЖДОЕ тело, мысленно выполни 6 проверок:

☐ РАСКРУТИ: Мысленно раскрути 3 случайных комбинации. Все 3 — грамматически идеальны?
☐ INBOX-ТЕСТ: Если бы ты получил это письмо от незнакомца — ты бы кликнул по ссылке из ЛЮБОПЫТСТВА? Или сразу нажал бы «спам»?
☐ SPAM-ТЕСТ: Есть ли хотя бы одно слово из запрещённого списка? Есть ли «!!!», КАПС, >2 ссылок?
