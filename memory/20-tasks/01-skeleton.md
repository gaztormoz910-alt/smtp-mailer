# Задача 1 — Каркас проекта и 5 вкладок

## Что реализовано
Каркас десктоп-приложения на CustomTkinter (тёмная тема) — основа, на которую
навешивались все последующие функции (задачи 2–12).

- `main.py` — точка входа: создаёт каталоги `data/`, `data/presets/`, `logs/`
  (если нет), патчит `CTkScrollableFrame` (авто-скрытие скроллбара + отступы),
  ставит тёмную тему, запускает `App().mainloop()`.
- `gui/window.py` — главное окно `App` (наследник `ctk.CTk`): `CTkTabview` с
  вкладками, создание общих менеджеров, инжект их во вкладки, переключение вкладок.
- `gui/theme.py` — палитра и шрифты (фон `#0a0a0a`, акцент `#4ade80`, ошибка
  `#ef4444`, предупреждение `#fbbf24`; шрифты Segoe UI / Consolas).

## Вкладки
Изначально пять: **Настройки (Setup)**, **Контент (Content)**, **Кампания
(Campaign)**, **Отправка (Send)**, **Статистика (Stats)**. Позже добавлена шестая —
**План** (распределение писем между SMTP), см. `gui/tab_plan.py`.

## Решения
- CustomTkinter вместо голого Tkinter — готовые тёмные виджеты, скруглённые углы.
- Общие менеджеры (`ProxyManager`, `SmtpManager`, `ContentManager`, `SendStats`)
  создаются один раз в `App` и инжектируются во вкладки — единое состояние.
- Вся тяжёлая работа — в daemon-потоках; GUI обновляется через `parent.after(0, …)`.
