## Что изменилось для тебя на практике

1. **Заголовки станут короче** — нейросеть теперь обязана считать длину по САМОМУ ДЛИННОМУ варианту раскрытия, а не по сырому шаблону. Больше никаких 12-словных тем.

2. **Plain Text тела больше не будут содержать HTML-теги** — раньше промпт требовал `<a>` в Plain Text режиме, нейросеть могла путаться и вставлять HTML в чистый текст.

3. **Не будет фейковых Unsubscribe блоков** — убрано требование «отписка в самом низу» из обоих промптов. Софт добавляет unsubscribe автоматически, дублирование в шаблоне = спам-триггер.

4. **Пример в промпте Subjects теперь корректный** — старый пример сам нарушал правило длины, подавая нейросети плохой образец.
